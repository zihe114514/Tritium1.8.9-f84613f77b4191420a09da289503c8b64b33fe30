# S0 源码审计总报告 · Deuterium 网易云播放器 → Minecraft 1.8.9 Forge 独立 Mod

> 日期 2026-08-14。本文是 S0 阶段的最终交付物，汇总 6 份子报告：`architecture.md`（适配层设计）、`ncm-api.md`、`audio.md`、`ui.md`、`renderer.md`、`support.md`。审计全部只读，未改动原源码。

## 0. 一页结论

Deuterium 是 **Opai 客户端（`today.opai.api`）的「音乐扩展」**，播放器本体（API/加密/音频/UI/渲染逻辑）**几乎全部可原样复用**。移植到独立 Forge 1.8.9 Mod 的实质工作只有 4 类：

| # | 工作 | 性质 | 规模 |
|---|---|---|---|
| ① | 为 `today.opai.api` 造一个 **Forge 1.8.9 适配层（shim）** | C 适配 | ~17 类型 / ~30 GL 方法，全部 1:1 映射 |
| ② | **Java 21→8 全量语法降级** | B 机械改写 | switch 表达式 97 处/14 文件、SequencedCollection ~25 处、instanceof 模式 7 处、虚拟线程 1 处、其他零散若干 |
| ③ | 补 3 个外部 jar | 工程化 | lombok(编译期)、**zxing-core**(登录二维码)、jna(MC 已内置，可选) |
| ④ | **Forge 生命周期接线** | C 适配 | `@Mod` 入口 + 事件总线 + `Minecraft.displayGuiScreen` |

**关键利好**：
- 加密链路**完整自包含**（`CryptoUtil` 硬编码 weapi/linuxapi/eapi 全部密钥），P0 直接复用，不碰加密。
- **纯 LWJGL 2，零 LWJGL 3**；shader/FBO/stencil/模糊全部是 MC 1.8.9 已有能力，无需引入新渲染能力。
- 音频走 JavaSound（JDK 内置），1.8.9 JRE 可用，**无需改写即可出声**。
- UI 页面状态机/布局/交互/歌词逻辑 **100% 复用**。

**唯一功能损失**：「灵动岛歌词」依赖 Opai 客户端反射 + 原生字节码注入，Forge 下无法等价移植 → 记为**限制**（`DYNAMIC_ISLAND_SUPPORTED=false`）。

## 3. A/B/C/D/E 分类汇总

### A 直接复用（纯 Java 或 MC 已内置库，拷贝即用）— 约 120+ 文件
- **API/加密/数据（P0）**：`CryptoUtil`、`OptionsUtil`、`RequestUtil`、`StringUtils`、`CloudMusicApi`、`math/*`(11)、`music/dto/*`(5)、`music/Quality`
- **音频库**：JSyn 核心、JLayer(decoder+converter)、jFLAC 解码链、processing.sound 核心、jipes FFT、softsynth（含若干 B 语法点）
- **纯工具类**：`Lazy`、`Tuple`、`Location`、`Mth`、`other/StringUtils`、`WrappedInputStream`、`Timer`、`logging/*`、`JsonUtils`、`KeyboardUtils`、`HttpUtils`、`AbstractManager`、`ClientSettings`
- **动画/图元纯类**：`Easing`、`Animation`、`SpringAnimation`、`SpringParams`、`QueuedParams`、`QueuedPosition`、`GaussianKernel`、`RGBA`、`ChatAllowedCharacters`、`Glyph`、`FontKerning`、`FilterState`、`ITextureObject`、`BooleanState`、`Shader`(抽象)
- **UI 纯逻辑**：`NCMPanel`、`LyricLine`、`ControlsBar`、`HomePanel`、`MusicWidget`、`SpectrumVisualizer`

### B Java 8 降级（机械改写，不改行为）— 约 20 文件
| 模式 | 数量 | 代表文件 |
|---|---|---|
| switch 表达式 `case X ->` / `yield` | 97 处 / 14 文件 | tritium: NCMScreen/FontManager/TextField/ScrollPanel/CFontRenderer/LogManager/MusicLyricsWidget + repackage: IFFParser/RiffFile/RiffStream/Bitstream/Header/OutputChannels/ChannelFixed |
| `getFirst/getLast/removeFirst/removeLast` | ~25 处 | CloudMusic/LyricParser/NCMScreen/MusicLyricsWidget/MultipleEndpointAnimation + SynthesisEngine/UnitDataQueuePort/ScheduledQueue |
| `instanceof X pattern` | 7 处 | SequentialDataCrossfade/OutputChannels/FLACDecoder/NavigateBar/LogManager |
| `Stream.toList()` | 2 处 | Music/NavigateBar |
| `String.repeat()` | 1 处 | TextField |
| `readAllBytes()` | 1 处 | CloudMusic |
| `inetAddresses()+Optional.isEmpty()` | 1 处 | DeviceIdGenerator |
| `Math.clamp()` | 1 处 | MusicLyricsWidget |
| **虚拟线程 `newVirtualThreadPerTaskExecutor()`** | 1 处 | **MultiThreadingUtil（全局异步执行器）→ `newCachedThreadPool()`** |

### C Forge 1.8.9 适配（换基类/事件/线程，逻辑不变）— 渲染层几乎全部 + UI 骨架 + 胶水
- **渲染层**：`Framebuffer`/`Image`/`Rect`/`StencilClipManager`/`TextureManager`/`TextureUtil`/`RenderSystem`/`AnimatedTexture`/`MusicToast`/`ScrollText`/`Interpolations`/`CFontRenderer`/`GlyphGenerator`/`TextureAtlas`/`AbstractTexture`/`DynamicTexture`/`Textures`/shader 全部(12+)/texture/ui 全部(15)
- **UI 骨架**：`NCMScreen`、`CoverflowOverlay`、`MusicLyricsPanel`、`LoginRenderer`、`PlaylistPanel`、`MusicInfoWidget`/`MusicLyricsWidget`/`MusicSpectrumWidget`
- **胶水**：`TritiumMusicExtension`、`TritiumEventHandler`、`SharedConstants`、`SharedRenderingConstants`、`OpenNCMScreen`、`AudioPlayer`
- **核心适配点**：`api.getGLStateManager().xxx()` → `GlStateManager.xxx()`（~30 方法 1:1）；`ExtensionScreen→GuiScreen`；`ExtensionModule/ExtensionWidget→自建基类`；`Display.getWidth→ScaledResolution`；`api.displayScreen→Minecraft.displayGuiScreen`；`addScheduledTask→Minecraft.addScheduledTask`；`onLoop→ClientTickEvent`；`onRender2D→RenderGameOverlayEvent`；`EventRender2D.getWindowResolution→ScaledResolution`；`getFontUtil().getVanillaFont→fontRendererObj`；`getShaderUtil().drawWithBloom→Shaders.BLOOM_SHADER`；ValueManager 4 种值类型自建。

### D 必须重写 — 1 文件
- **`CloudMusic.java`**：播放队列(PlayThread/prev/next/playMode)、歌词状态机、登录、封面/下载逻辑是 P0 必须保留，但重度耦合 `tritium.rendering.*`/`tritium.screens.ncm.*`/`TritiumMusicExtension`/`today.opai.api`，需**解耦抽取**成「播放/歌词核心」与「UI/渲染/框架」两层后移植。

### E 删除
- `ExtensionEntry`（入口，由 @Mod 替代）、`interfaces/User32Interface`（纯 JNA Win 光标绑定）
- `reflection/` 5 文件（ClassFinder/CommonReflectionClasses/Reflection/ReflectionClasses/ReflectionUtils）+ ASM 依赖（仅灵动岛字节码注入使用）
- `me/fan87/nativeinstrumentation/` 4 文件 + `native_instrumentation_native-windows-x86_64.dll`
- repackage 死代码：`processing.sound.{Sound,Amplitude,Waveform}`、`JSyn.{FourierMath,PeakFollower,ShortSample,AIFFFileParser}`、`jFLAC.{FLACEncoder,WavWriter}`、`CloudMusic.convertFlacToWav/convertMp3ToWav`

> **S0.6 审计勘误（2026-08-14 已复核源码）**：初版误将 `utils/WidgetWrapper` 与 `utils/cursor/CursorUtils` 归为 E。复核确认：`WidgetWrapper.createWrapper` 被三个 HUD widget（MusicInfo/MusicLyrics/MusicSpectrum）调用，属 **C 保留**；`CursorUtils` 被 NCMScreen 调用（setCursor/resetOverride/setOverride），属 **C 适配**（剥离 JNA/WindowsDisplay 反射，降级为 no-op 存根，仅其依赖 `User32Interface` 为 E 删除）。

## 5. 关键限制（按 CLAUDE.md §14 记录）

| 项 | 限制 | 降级方案 |
|---|---|---|
| **灵动岛歌词**（`dynIsland` 设置项） | 依赖 Opai 动态岛水印类 + ASM 字节码注入 + 原生 JNI，Forge 无目标类 | `DYNAMIC_ISLAND_SUPPORTED=false`，设置项隐藏；歌词 HUD 其余 3 种效果（Scroll/FadeIn/SlideIn）完整保留 |
| Windows 系统光标装饰 | `User32Interface`/`CursorUtils` 是 JNA 改 Windows 光标 | 删除，用 MC 默认光标（不影响播放功能） |
| 音频不入 MC 主音量 | JavaSound 与 OpenAL 独立 | S3 先用 JavaSound 跑通（`player.amp` 自管音量）；S6/S7 可选 OpenAL 适配器 |
| `blur.frag`/`stencil.frag` 为 `#version 130` | 极老 GL2.1 驱动编译失败 | 降级 `#version 120` + `texture()→texture2D()` |

## 6. 分阶段实施计划（S1–S7）

- **S1 Forge 基础工程**：`@Mod` 入口替代 ExtensionEntry；建 shim 骨架（`OpenAPI` 适配器/`GLStateManager` 包装/`ValueManager`/`ExtensionScreen→GuiScreen`/`ExtensionModule/Widget` 基类）；删 E 类文件与 ASM/dll；build.gradle 加 lombok+zxing；跑通 `gradlew build`。
- **S2 API**：搬入 ncm 包（API/加密/数据/dto）+ utils + logging；Java8 降级 + 虚拟线程→线程池；验证搜索/详情/播放地址/歌词链路异步可用。
- **S3 音频**：搬入 repackage 音频栈 + AudioPlayer + SpectrumVisualizer；Java8 降级（switch/instanceof）；验证真实 MP3/FLAC 播放/暂停/Seek/上下首/停止 + FFT 频谱。
- **S4 基础 UI**：搬入 rendering 层 + shader/字体/纹理/动画 + widget 树；shim GLStateManager/RenderSystem/ScaledResolution；验证 NCMScreen 全屏播放器、控制栏、封面、进度条、歌词。
- **S5 完整 UI**：HomePanel/PlaylistPanel/NavigateBar/Coverflow/LoginRenderer/HUD 三件套；事件接线（ClientTickEvent/RenderGameOverlayEvent）；验证搜索、歌单、Coverflow、动画、HUD、频谱。
- **S6 渲染高保真**：圆角/裁剪/模糊/Bloom/Shader 逐项对照；`blur/stencil` shader 降级；回归原项目视觉。
- **S7 回归**：原项目 vs 1.8.9 逐项对照；clean build；干净客户端测试。

**每阶段独立编译+运行+回归**，不做一次性大修。

## 7. 待确认的决策点（S1 前）

1. **lombok 处理方式**：优先 `compileOnly lombok`（改 0 文件）；若 Gradle 4.5 注解处理失败 → delombok（机械展开 getter/setter，改动大）。默认先试 lombok。
2. **DeviceIdGenerator 的 JNA**：优先保留（MC 内置 jna）；若 S1 验证未内置 → 降级为 `System.getProperty`（设备 ID 稳定性略降）。默认先试 JNA。
3. 是否直接按上述 S1 方案开工（删 E 类文件 + 建 shim 骨架 + 跑通 build）。
