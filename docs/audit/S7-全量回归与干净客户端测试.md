**⚠️ Windows 文件锁 caveat（首次 clean 失败，已解决）**：
首次 `clean build` 在 `:clean` 失败：`Unable to delete file: build\taskLogs\retromapReplacedMain.log`。
根因是上一轮 `runClient`/构建遗留的 **2 个 Gradle daemon** 仍持有该文件句柄。
`./gradlew --stop`（停止 2 daemon）后重跑 clean build 成功。
**复现规避**：Windows 下 clean 前先 `gradlew --stop`，或关闭仍在运行的客户端/IDE 索引。

> 注：`clean build` 的 `:test` 为 JUnit 空跑；两条冒烟测试是独立 `JavaExec` 任务（`smokeTest`/`audioSmokeTest`），不在 `:test` 内，见 §1.1。

## 3. 已知限制（不可移植项，均已按 §14 记录）

| # | 限制 | 原因 | 现状 |
|---|---|---|---|
| 1 | **灵动岛歌词**（`dynIsland` 设置项） | Opai 客户端水印 + ASM 字节码注入 + 原生 JNI，Forge 无目标类 | `Reflection` 为 E 存根，`DYNAMIC_ISLAND_SUPPORTED=false`，设置项隐藏；歌词 HUD 其余 3 种效果（Scroll/FadeIn/SlideIn）完整保留 |
| 2 | **音频不入 MC 主音量** | JavaSound 与 OpenAL 独立 | `player.amp()` 自管音量；S6/S7 可选 OpenAL 适配器（方案 2，未做） |
| 3 | **HUD Widget 默认位置 (0,0)** | Opai HUD 编辑器/拖拽持久化缺失 | 默认关闭；如需启用需补最小 C 适配（默认坐标） |
| 4 | **中文 IME 候选窗（`IngameIME.dll`）** | 打包了 `src/main/resources/tritium/IngameIME.dll`，但**无任何 Java 代码加载它**（grep 无 `System.load`/`Native.load`/`IngameIME` 引用） | 搜索框中文输入依赖系统 IME 直接产生 unicode 字符，可能仍可用；候选窗定位/英文占位可能失效。**干净客户端须实测中文搜索** |
| 5 | **FFT 频谱回调在 headless 下抛 `NoClassDefFoundError`**（仅影响冒烟测试，非 MC 运行） | `AudioPlayer` 静态 FFT 回调 → `SpectrumVisualizer.processFFT` → `TritiumMusicExtension.getInstance()` → `OpenNCMScreen` 字段初始化 `SharedConstants.api`（=`Extension.getAPI()`，preInit 前为 null）。`SharedConstants` javadoc 已明示「实现类必须晚于 preInit 加载」 | 在 MC 中 preInit 先于任何音频播放，频谱正常；**headless 冒烟测试无法验证频谱**，须在干净客户端 #18 真机确认。播放链路不受影响（异常只发生在 FFT 回调，不阻断音频输出） |

## 4. 干净客户端测试清单（由用户执行，S7 验收）

> 前置：`gradlew --stop`（避免文件锁）→ `./gradlew clean build` → 全新 profile 启动干净 1.8.9 Forge 客户端（仅本 Mod，无其它 Mod 干扰）。

### 4.1 启动与基础
1. Mod 正常加载（Mods 列表可见 DeuteriumMusic 1.0.2）。
2. 按 **M** 打开全屏播放器，UI 无崩溃、无字体 NPE。
3. 反复开关 UI，无资源泄漏/崩溃。

### 4.2 API 与搜索

6. 点击结果 → 歌曲详情 / 播放。

### 4.3 音频播放
7. 真实播放一首 mp3（若无版权则换歌）：有声音、进度走动。
8. 播放/暂停/上下首/播放模式（循环/随机）切换正常。
9. Seek 拖动/点击进度条生效。
10. 音量调节生效。
11. 切歌后 HUD toast（`MusicToast`）弹出。

### 4.4 歌词与封面
12. 歌词逐行高亮；逐字歌词（karaoke）滚动、**裁剪正确**（验证 S6-2 #2.1）。
13. 封面显示；封面背景高斯模糊正常。
14. 封面高光 Bloom 正常。
15. 翻译/罗马音歌词（若歌曲有）切换显示正常。

### 4.5 渲染高保真
16. 圆角、阴影、Hover/Press 反馈与原项目一致。
17. 歌单/Coverflow 页面转场与动画正常。
18. 频谱（若启用 HUD）随播放跳动。
19. **GUI 缩放 > 1 时，歌词模糊强度是否异常**（验证 S6-2 #2.2 texel 单位不一致）。
20. 逐字歌词 karaoke 的 shader 裁剪、滚动文本淡边正常。

### 4.6 已知限制确认（预期不工作，非回归）
21. 灵动岛歌词设置项**不出现**（预期，E 存根）。
22. 非 Windows 平台光标切换自动禁用（预期）；Windows 下 hover 光标应切换。
